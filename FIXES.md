# Исправления v0.8.1

| Ошибка | Исправление | Проверка |
|---|---|---|
| Rejected навсегда блокировал защиту | Отдельное постоянное обязательство, UUID попытки, lease, ограниченный retry | Независимый тест + restart/throttle/concurrency |
| Partial SELL оставляла dust | Проверка остатка до изменения баланса; отдельное подтверждение full close | Независимый тест + неизменность cash/position |
| Refresh правил не восстанавливал защиту | Fingerprint ограничений, новая попытка после изменения, периодическое обновление rules | Независимый тест + step/max/tick recovery |
| Live при отсутствии bid/ask | Независимые состояния готовности, timestamps сторон, Spot orderbook.1 | Независимый тест + missing/inverted/stale/out-of-order |
| Защита зависела от fragment UI | Локальный worker процесса с heartbeat и предупреждением | Worker закрывает позицию в тесте без UI |
| Параметры по умолчанию менялись на сервере, оставаясь прежними в JS | Начальные параметры фиксируются один раз при готовой котировке и сохраняются до изменения пользователем/контекста | Повторная браузерная проверка при изменении рыночного состояния |
| Старый сигнал выглядел текущим | Persistent lifecycle, TTL, диапазон входа, Opportunity Missed | Lifecycle tests и browser |
| Исторический маркер не объяснял задержку | Маркер границы закрытия, tooltip фактического обнаружения | Browser + неизменность confirmed history |

Файл `tests/MOEX_v08_regression_tests.py` получен из предоставленного Library-файла и не редактировался. Его четыре ошибки воспроизведены до исправления; результат сохранён в `docs/v0.8.1/regressions-before.txt`.
