# Демонстрация rc3

Запустите setup.command/start.command по README. Откройте Trade, BTCUSDT, 15m. Публичные свечи идут только из настоящего Bybit connector. При недоступном API приложение показывает ошибку; встроенного подменяющего рынка нет.

«Тренд + сигналы» включает causal Trend Ribbon и маркеры. Glow и интенсивность находятся в настройках слоя; reset возвращает 85%. Смена масштаба/слоёв сохраняет chart instance. Assistant можно свернуть.

Для тренировки выберите Paper Trading, задайте 25 USDT, изучите preview и подтвердите. Затем измените Stop/Target через отдельное подтверждение, продайте часть/доступное количество, откройте Performance и проверьте расходы/P&L.

Скриншоты docs/rc3/browser — реальные снимки браузера на tests/crypto_ui_fixture.py с крупной надписью об искусственных QA-свечах. Они служат только проверке интерфейса. docs/rc3/production/bybit-connection.png показывает настоящий результат запуска без fixture в этой среде.

Bybit Demo здесь не подключён: LOCAL PAPER не является официальным Demo-аккаунтом.
