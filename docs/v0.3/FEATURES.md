# Статус функций

| Требование | Статус | Практическая граница |
|---|---|---|
| Аудит трёх исходников | Выполнено | Проверены архивы, не текущая папка Desktop |
| Сохранение Reader | Выполнено | 5 прежних инструментов и 15 неизменённых тестов |
| Общий источник UI / MCP | Выполнено | Одна реализация DataEngine; отдельный RAM-кеш каждого процесса |
| SBER / история / симуляция | Выполнено | Проверено живым MOEX и общим bridge |
| Акции и фонды | Выполнено | Основной текущий режим, цены без корректировок |
| Облигации | Частично | Карточка, котировка, история; цена в % номинала |
| Кеш / ошибки / provenance | Выполнено | TTL RAM, строгие данные, source/time/SHA/coverage |
| Monte Carlo / блоки / seed | Выполнено | Исторический bootstrap, не прогноз |
| VaR / ES / волатильность / просадка | Выполнено | Определения и знаки в архитектуре |
| Комиссия / проскальзывание | Выполнено | Параметрическая модель; не реальное исполнение |
| Сравнение сценариев | Выполнено | Три явно заданных чувствительности, без весов вероятности |
| Buy & Hold / MA / RSI | Выполнено | Long-only, next-open, постоянный лот, final liquidation |
| Пользовательская Python-стратегия | Выполнено через API | Только доверенный локальный код, пример включён |
| Бенчмарк / отложенный период | Выполнено | Один временной split; автоматического подбора нет |
| Виртуальный журнал | Выполнено | SQLite, ручной ввод, JSON-экспорт |
| Доходность и просадка портфеля | Выполнено через CSV/API | Требуется полная история дневных оценок, начало-дневные потоки |
| Структура и стресс | Выполнено | Ручные оценки, ценовые шоки, сравнение доли денег |
| Дивиденды / купоны | Частично | Только ручные денежные события с указанным источником |
| AI Research | MCP + численный отчёт | Интерпретация во внешнем ИИ-клиенте; встроенного чата нет |
| Mac Apple Silicon | Подготовлено | Python без платформенного кода, разрешение зависимостей проверено; физический Mac не тестировался |
| Публичный защищённый MCP | Отложено | Только локальный stdio/HTTP; публичный bind запрещён |
| Total-return и corporate actions | Отложено | Дивиденды/сплиты в рядах цен не корректируются |
| Bond cash-flow / FX / multiasset covariance | Отложено | Не подменяются equity-моделью |
| Walk-forward / подбор гиперпараметров | Отложено | Чтобы не выдавать простую подгонку за качество |
| Автоматическая переоценка портфеля | Отложено | Источники/даты вводятся пользователем |
| Редактирование/удаление журнала в UI | Отложено | Append-only, восстановление в новую базу через Python |
| GitHub публикация | Не выполнялась | Структура Git-ready; репозиторий пользователь не выбирал |

MVP завершает основной исследовательский цикл и оставляет явные границы расширения. Он не является сертифицированной системой оценки рисков или доказательством прибыльности стратегий.
