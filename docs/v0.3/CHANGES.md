# Изменения 0.3.0

Объединены предоставленный MOEX Reader, Time Machine v0.1 и bridge v0.2. Сетевой путь и расчёты общие для UI и MCP; исходные ZIP сохранены без изменений.

- Сохранены пять инструментов Reader, их аргументы и старый отдельный запуск. Единый MCP добавляет восемь инструментов исследований, всего 13.
- Сохранён bootstrap и прежние поля его результата. Добавлены VaR/ES, просадки ликвидируемой позиции, историческая волатильность, сценарная чувствительность, защита от переполнения, строгая валидация и лимит нагрузки.
- Исправлены реальная схема MOEX instrument detail, silent row dropping, sync/async bridge и MCP output schema.
- Добавлены общая нормализация данных, source/coverage/fingerprint, ограниченный TTL-кеш с сохранением времени загрузки и отдельные пути bonds/shares.
- Добавлены Buy & Hold, MA и RSI/Wilder, next-open execution, лоты, затраты, holdout и локальные Python-стратегии с передачей только префикса истории.
- Добавлен виртуальный рублёвый портфель: SQLite, журнал, проверки cash/positions, выплаты с источником, ручная оценка, TWR по CSV и стресс.
- Streamlit переведён в единый тёмный интерфейс с шестью разделами. Сохранены графики и CSV; добавлены численный отчёт и Markdown-экспорт.
- Прямые/транзитивные зависимости зафиксированы с хешами. Добавлены конфигурация, JSON-логи, `.gitignore`, документация и проверочные скрипты.

## Намеренные изменения поведения

Невалидные CLOSE/даты теперь вызывают ошибку вместо удаления строки. Облигации не подаются в equity-simulator. Demo имеет фиксированный календарь. Публичный HTTP-хост и старый PUBLIC_HOST отключены до появления авторизации. Лимит сценариев уменьшен до 50 000 и дополнен ограничением размера матрицы. Все эти изменения защищают достоверность или устойчивость приложения и описаны в README.

## Что не было сделано

Нет брокерского подключения, торговых приказов, автоматической торговли, обещаний доходности, публикации в GitHub или облаке. Не заявляется воспроизведение более позднего содержимого пользовательской папки Desktop, не входившего в найденный ZIP.
