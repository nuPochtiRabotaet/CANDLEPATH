# Аудит v0.6 → v0.7

Источник: неизменённый MOEX_Intelligence_v0.6.0.zip, SHA256 729087d158a20cb5230fbbeb10e0278aa69b4bb1022e218c8a229cb905f31720. Разработка ведётся в отдельной директории v0.7; оригинальный архив не перезаписывается. Полный перечень исходных модулей, публичных функций и SHA256: baseline-files.json. Зависимости зафиксированы исходными requirements*.txt, Python 3.12.14. Первое восстановление тестовой среды выявило отсутствие pytest-asyncio в самой среде; плагин установлен из существующей dev-спецификации.

## Приоритеты и финансовые границы

1. Навигация повторяет модули: Laboratory находится внутри Research, History занимает отдельный главный пункт. Заменить четырьмя задачами: Обзор / Портфель / Лаборатория / Исследования.
2. Одобренный HTML-прототип не интегрирован: lab_ui.trade_panel имеет длинную последовательность виджетов, отдельные таблицы и фрагментарные rerun. Компонент v2 поддерживается фактическим Streamlit 1.66.1. Он позволяет сохранить Python/Plotly без Node-сборки, React и отдельного сервера.
3. Рыночная история уже кэшируется отдельно от цены, модель отдельно от количества. Сохранить разделение; не загружать историю при каждом изменении количества/стресса.
4. Расчёты по рублёвым облигациям корректно используют LAST% × FACEVALUE / 100 + ACCRUEDINT. Не менять модель акции на облигационную без купонов/амортизации.
5. Общая стоимость скрывается при неизвестных оценках других позиций; неизвестная комиссия не равна нулю. Эти ограничения сохранить.
6. Историческая средняя учётная цена при переносе — ввод пользователя. Доходность до переноса неизвестна. Денежные пополнения не являются прибылью.
7. Классы доступны в marks; отрасль, сквозной состав фонда и эмитент не нормализованы. Не угадывать классификацию: показать ограничение.
8. Нет сохранённой исторической оценки портфеля по умолчанию. До загрузки корректной истории показывать честное пустое состояние вместо графика одной акции под названием портфеля.
9. Live ISS, Safari и физический Mac требуют отдельной проверки. Unit-тесты не подтверждают точность визуального переноса и не подтверждают доступность биржи.

Рабочие модели, форматы SQLite, MCP, импорт, корректировки и launcher сохраняются. UI-регрессии проверяются отдельно от математических регрессий; изменение названия/маршрута не означает удаление финансовой функции.
