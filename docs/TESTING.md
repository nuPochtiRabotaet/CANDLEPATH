Тестовые цены и история — явно обозначенные fixtures. Они не попадают в продукт как live-котировки. Прогностическое качество модели не объявлено подтверждённым: чистые математические и UI-тесты не доказывают способность предсказывать рынок.

Проверка интерфейса выполнена Streamlit AppTest с реальными обработчиками/кешем; полноценный Chromium/Safari в этой итерации не запускался. Optional `scripts/verify_browser.py` обновлён для новой навигации, но его текущий прогон не заявлен. Физический Apple Silicon, Finder/Gatekeeper и Python 3.13 не проверены. Новая чистая установка не повторялась: используются прежние проверенные зависимости без изменения locks.

Фактические будущие исходы сохранённых сценариев ещё не проверены; доступна команда сравнения после накопления нужного числа закрытий. Нативный отчёт Альфы, автоматическая брокерская синхронизация, сквозной состав фондов и совместная портфельная VaR в этот подтверждённый результат не входят.

## Повторить

```bash
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m scripts.verify_http
```

Для live требуется доступный MOEX ISS; автоматического перехода на demo нет. Сборка: `python -m scripts.package_release`. ZIP содержит manifest SHA-256 и исключает личные базы, кеш котировок, runtime, git-метаданные, секреты и скриншоты.
