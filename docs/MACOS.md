# Установка на macOS / Apple Silicon

Рекомендуется Python 3.12 из официального universal2-установщика python.org. Не используйте `sudo pip`. Архив содержит исходники, окружение создаётся на вашем Mac. Сборки Python 3.13 отдельно не тестировались.

1. Распакуйте `MOEX_Intelligence_v0.7.1.zip` в Downloads или другую доступную для записи папку.
2. В Finder откройте `setup.command`, дождитесь окончания установки (интернет нужен для PyPI).
3. Откройте `start.command`. Повторный запуск открывает тот же собственный сервер.
4. Откройте `stop.command` для завершения. Данные сохранятся.

Если Finder не запускает скрипт, откройте Terminal:

```bash
cd ~/Downloads/moex-intelligence-v0.7.1
chmod u+x setup.command start.command stop.command check_moex.command
bash setup.command
bash start.command
```

При блокировке Gatekeeper проверьте происхождение архива и используйте предусмотренное macOS открытие конкретного файла через контекстное меню/настройки безопасности. Не отключайте защиту глобально. Если установка оборвалась, повторите setup: существующее окружение используется повторно. Если оно создано неверной версией Python, переименуйте `.venv` и повторите setup с Python 3.12.

Сервер слушает только 127.0.0.1. Если порт 8501 занят, выбирается 8502–8510. Ссылка печатается в Terminal; её можно открыть в Safari/Chrome вручную. При занятости всех портов запуск прекращается с объяснением. Лог: `.runtime/app.log`. Статус: `.venv/bin/python -m moex_intelligence.launcher status`.

Launcher использует локальный supervisor с непредсказуемым токеном, сохранённым с правами 0600. Сам PID не служит основанием для остановки процесса. Supervisor завершает только созданный им дочерний процесс Streamlit. Устаревший state удаляется без сигналов чужому процессу. Одновременные старты из нескольких терминалов не синхронизированы; запускайте последовательно.

Для разработки: `requirements-dev.txt` включает тесты. Playwright — дополнительный инструмент QA, приложению не требуется. Все зависимости закреплены с хешами. ARM64 разрешение зависимостей из предыдущей версии сохранено в `docs/v0.3/macos-arm64-resolution.txt`; зависимости v0.7.1 не менялись. Это проверка пакетов, а не замена запуска на реальном Mac.

При ошибке ISS проверьте соединение и влияние своего VPN на доступ к `https://iss.moex.com`. Демо включается только вручную, не требует MOEX. Проверка установки, Gatekeeper, double-click Finder и Safari на физическом Mac в этой среде не проводилась.

## Переход с v0.7

Остановите старую папку через её `stop.command`. Распакуйте v0.7.1 в новую папку, не переносите старую `.venv`. После `setup.command` запустите новую версию. Она использует прежний каталог данных и создаёт одноразовый checkpoint `~/.moex-intelligence/backups/before-v0.7.1/` перед чтением баз. Если вы задавали `MOEX_DATA_DIR`, сохраните то же значение. Не редактируйте один журнал одновременно из двух версий.

Для проверки сети откройте `check_moex.command` или выполните:

```bash
.venv/bin/python -m scripts.diagnose_moex --quotes --output .runtime/moex-diagnostic.json
```

Прямой DNS/TLS может быть недоступен при рабочем proxy: смотрите результаты всех маршрутов и трёх котировок, а не только первую строку. Ошибка диагностики не превращает сохранённую цену в текущую.

## Приёмка на физическом Mac / Safari

1. Запустите setup и start через Finder; проверьте адрес и отсутствие второго сервера при повторном старте.
2. Откройте приложение в Safari и Chrome. Проверьте обзор, выбор позиции, ± и ползунок, покупку и продажу, комиссию, до/после, сброс и возврат к выбранной позиции.
3. Для облигации сравните чистую цену, номинал и НКД с источником. Для реального тарифа сверяйте полную стоимость с вашим брокером.
4. Сеть включена: нажмите обновление и раскройте даты источника. Сеть выключена: сохранённая цена должна остаться с исходным временем и пометкой сохранения.
5. Проверьте ваш настоящий отчёт сначала в предпросмотре без сохранения. Импортируйте только после сверки; повтор должен распознать дубли.
6. Закройте сервер через stop, запустите снова, убедитесь, что журнал сохранён. Оставьте резервную копию до обновления отдельно.

Это чек-лист оставшейся проверки, а не заявление о её прохождении.
