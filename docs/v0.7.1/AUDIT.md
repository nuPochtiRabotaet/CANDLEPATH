## Архитектурное решение

Сохранены Streamlit 1.66.1 и Plotly 6.9.0 из исходного окружения. Финансовые модели и SQLite-журнал переиспользуются. Нативные компоненты v2 уже поддерживают локальное состояние и двусторонние сообщения; отдельные React/Node backend и runtime-зависимости не добавлялись. Plotly поставляется с Python-пакетом, без CDN. Для CSS/HTML экранируются внешние строки, DOM-элементы заполняются через `textContent`.

Проверены официальные возможности: [Streamlit v2 registration / cleanup](https://docs.streamlit.io/develop/api-reference/custom-components/st.components.v2.component), [двусторонние сообщения](https://docs.streamlit.io/develop/concepts/custom-components/components-v2/register), [Plotly.react / relayout](https://plotly.com/javascript/plotlyjs-function-reference/). Возможности подтверждены также установленными пакетами и реальным браузером.

`portfolio.py`, `portfolio_import.py`, `laboratory.py`, `advisor.py`, `risk.py`, `decision.py`, `backtest.py`, persistence, MCP, launcher и закреплённые зависимости побайтово совпадают с исходной версией. Целенаправленно изменены адаптеры представления/метаданные, обработка неполных котировок и сценарные заключения. Предварительная арифметика JS необходима для мгновенного UI; финансовый Python replay остаётся обязательной проверкой, а не вторым новым финансовым ядром.

## Визуальный аудит после запуска

[Галерея реальных снимков до/после](screenshots.html).

Первый акцент обзора — капитал; основное действие — проверка покупки рядом с переходом в портфель. Пустая история занимает короткий блок и не вытесняет текущую структуру. На портфельном экране сначала таблица, затем выбранная позиция с тремя действиями; источник и подробности свёрнуты. На 1440×900 действия выбранной позиции видны в первом экране. Лаборатория сохраняет управление слева и результат справа; на телефоне блоки последовательно складываются. Изменения долей помечены п.п., суммы — рублями. В исследованиях первым идёт та же карточка актива; данные и методология доступны раскрытием.

По просмотренным снимкам исправлены закрывающая мобильный заголовок и перехватывающая клики нативная шапка, источник учебного актива в исследованиях, отсутствовавшая доля позиции и избыточная точность облигационной цены. Тесты ждут завершения переходов Streamlit. Для нативных кнопок с подсказками выбираются доступные видимые элементы: Streamlit содержит отдельную скрытую копию для другого размера экрана. Принудительные клики по скрытым контролам не используются.

## Три пользовательские перспективы

| Перспектива | Пройденный сценарий | Устранённые лишние действия | Что осталось |
|---|---|---|---|
| Начинающий | Обзор → портфель → оценить позицию → количество/комиссия → стресс → сброс | Повторный ввод тикера, поиск действий за источниками, лишняя кнопка расчёта | Тариф нужно подтвердить: он неизвестен приложению |
| Средний опыт | Переключение SBER/SBMX, сортировка стоимости, концентрация/потеря, закреплённый A | Сопоставление двух раздельных таблиц заменено до/после/разница | Сквозной состав фондов/эмитенты не исследуются автоматически |
| Продвинутый | История по требованию, смена горизонта, сохранение модели, подробный Advisor, источник | Повторный ввод суммы и срока; перезагрузка истории на лёгких изменениях | Совместимость условий Advisor ограничена его существующей моделью финансирования |

Это экспертное прохождение сценариев одним разработчиком на контролируемых данных, не исследование с тремя независимыми людьми. Полноценная внешняя UX-проверка и Mac/Safari остаются открытыми.
