# MOEX Intelligence v0.7.1

Локальная инвестиционная лаборатория на Python / Streamlit / Plotly. Биржевые данные — MOEX ISS; приложение не отправляет торговые приказы.

## Установка на вашем Mac

1. Остановите предыдущую версию через её `stop.command`.
2. Распакуйте этот архив целиком в отдельную папку `moex-intelligence-v0.7.1`. Папку v0.7 оставьте.
3. Откройте `setup.command`, дождитесь установки. Нужны Python 3.12 или 3.13 и интернет для пакетов.
4. Откройте `start.command`. Приложение откроется на `http://localhost:8501`; если порт занят, адрес будет напечатан в Terminal.
5. Для завершения используйте `stop.command` этой версии.

Если Finder не запускает скрипт:

```bash
cd ~/Desktop/moex-intelligence-v0.7.1
chmod u+x setup.command start.command stop.command check_moex.command
bash setup.command
bash start.command
```

Не копируйте `.venv` из старой папки. Новые runtime-зависимости не добавлены. Node, React, облако и отдельный веб-сервер приложению не требуются. Подробности: [docs/MACOS.md](docs/MACOS.md).

## Где что находится

- **Обзор** — стоимость капитала, деньги, документальные выплаты, до трёх наблюдений по реальному состоянию. История портфеля появляется только после загрузки корректных датированных оценок; график отдельной акции не выдаётся за график портфеля.
- **Портфель** — позиции, операции, выплаты, анализ и импорт. Карточка позиции открывает «Оценить», «Сценарии» или подтверждённую операцию без повторного выбора бумаги. Редактирование и удаление ошибочных записей, начальные остатки и импорт сохранены.
- **Лаборатория** — компактная песочница: лоты/бумаги, ±, ползунок количества, комиссия, покупка/продажа, до/после, изменение цены, ограничения и отдельные статистические сценарии. Рядом доступна финансовая цель.
- **Исследования** — актив, стратегии, Time Machine, история. Подробный Advisor, AI Research и MCP раскрываются в контексте исследования. Все прежние модели и экспорты сохранены.

Настройки профиля — кнопка в верхней области. Один интерфейс для любого опыта. Общие цвета, размеры и финансовые форматы определены в `design.py` и `formatting.py`. Выбранная позиция сохраняется при переходах между разделами.

## Как проверить решение

1. Из позиции нажмите «Сценарии»: приложение само передаст тикер и имеющееся количество. Предполагаемая операция изначально равна нулю.
2. Для новой покупки выберите бумагу в лаборатории. Цена, торговый лот и единицы поступают из MOEX. Если цены нет, система объяснит ограничение; ручная оценка задаётся явно и используется только в эксперименте.
3. Укажите проверенный тариф. Неизвестная комиссия не считается нулевой. Ставку можно явно запомнить.
4. Меняйте лоты/бумаги и ценовой стресс. Лёгкие показатели и Plotly-графики реагируют в браузере; Python затем независимо проверяет состояние существующими алгоритмами. Ошибочный лот, нехватка денег и продажа сверх остатка блокируют итог операции.
5. В «Оценить» подтвердите ограничения. Нарушение потерь, ликвидности или заданного предела концентрации выводится явно. Отсутствие конфликта не является положительной инвестиционной рекомендацией.
6. Раскройте «Сценарии статистической модели» для bootstrap. Смена количества и стресса не загружает историю заново. Гипотетический ползунок не изменяет модель.
7. «Сбросить сценарий» возвращает исходное состояние эксперимента. Ни одно из этих действий не меняет реальный журнал.

Облигации: полная рублёвая цена = чистая котировка в % × рублёвый номинал / 100 + НКД. Стресс меняет чистую цену, НКД фиксирован. Без подтверждённых обязательных параметров полная цена не выдумывается.

## Данные и обновление

По умолчанию данные остаются в `~/.moex-intelligence`, как в v0.7. Перед первым чтением существующих баз v0.7.1 создаёт одноразовую SQLite-копию в `backups/before-v0.7.1/`. Журнал, его ID, исправления и исследования совместимы; схема не менялась. Копия не перезаписывается последующими запусками.

Для возврата: остановите v0.7.1, сохраните текущие базы отдельно и запустите прежнюю папку v0.7. При необходимости восстановите файлы из `before-v0.7.1`, понимая, что более поздних записей в резервной копии нет. Не запускайте две версии одновременно при редактировании одного журнала.

## Что изменилось в v0.7.1

- Читаемые суммы и цены, общие компоненты источника данных, полная таблица позиций и карточки на телефоне.
- Мгновенная предварительная реакция с отдельным подтверждением Python. Защита от накопления обработчиков и запоздавших ответов, полное восстановление сценария, закрепление варианта A.
- Три итога проверки: конфликт, отсутствие конфликтов среди проверенных параметров, недостаточно данных. Прямая передача условий в подробный Advisor.
- Рыночное наблюдение, получение, сохранение и дата оценки показаны раздельно. Сохранённая цена сохраняет исходные даты. Время снимка ISS не называется временем последней сделки.
- Общий ограниченный кэш котировок для портфеля и лаборатории; история не загружается при движении ползунка.

## Проверка и ограничения

Аудит: [docs/v0.7.1/AUDIT.md](docs/v0.7.1/AUDIT.md). Результаты проверок и методика скорости: [docs/v0.7.1/TESTING.md](docs/v0.7.1/TESTING.md). Оценка по пяти направлениям: [docs/v0.7.1/SCORECARD.md](docs/v0.7.1/SCORECARD.md). Ограничения: [docs/v0.7.1/LIMITATIONS.md](docs/v0.7.1/LIMITATIONS.md). Снимки до/после находятся рядом с отчётами. Все показанные портфели в QA вымышлены и подписаны.

Если биржевые цены не загрузились, запустите `check_moex.command`. Отчёт появится в `.runtime/moex-diagnostic.json`. Он разделяет DNS, прямое TLS-соединение, системный proxy и запросы трёх котировок. Диагностика не отключает проверку SSL и не записывает адреса/пароли proxy.

В доступной Linux/Chromium среде пройдены 197 тестов, сквозные проверки и реальный запуск сервера. Внешняя сеть нестабильна: один ответ ISS с SYSTIME зафиксирован отдельно, последняя диагностика трёх котировок завершилась тайм-аутами. Физический Mac, Finder/Gatekeeper и Safari здесь не проверены; финальная приёмка на вашем Mac остаётся открытой. Демонстрационные данные не включаются автоматически в рабочем приложении.
