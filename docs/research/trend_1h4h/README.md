Исходная закрытая выборка Coliseum также защищена по её UTC-интервалу. Новый holdout длительностью 144 дня остаётся за верхней границей запросов. [Протокол](PROTOCOL.md)

В каждом периоде счёт начинает с 10 000 USDT. Обе гипотезы используют одни индикаторы, один последовательный движок и один календарь. Для каждой сделки движок проверяет исполнение на следующем открытии, гэпы, Stop-first, защитные ограничения и издержки. Размер позиции, допущения о ликвидности и принудительное закрытие на последней свече ограничивают интерпретацию результатов.

Успешный запуск вернёт по каждой комбинации `base` и `double`, число сделок, долю выигрышных сделок, средний чистый P&L в USDT, Profit Factor, чистый P&L и доходность в процентах от суммарного стартового капитала трёх периодов. Также сохраняются максимальная просадка по отметкам на открытии и закрытии внутри периода, издержки, результаты каждого периода и пассивные сравнения. Ниже разрешения OHLCV просадка может быть больше. По волатильности при входе и режиму на начало дня даётся описательная разбивка, включая дни в кэше.

В `statistics.columns` записан порядок 16 совместно проверяемых сравнений с USDT и 25% Buy & Hold. В `tests` содержатся средние дневные разности доходности в долях начального капитала, одновременные 95% интервалы и односторонние скорректированные p-значения. Основная длительность блока 7 дней, проверки устойчивости 3 и 14 дней. Даже положительный результат всех фильтров допускает лишь рассмотрение для независимой проверки.

## Воспроизведение

Команды запускаются из корня репозитория с установленными зависимостями.

```bash
.venv/bin/python scripts/run_trend_1h4h.py --output trend-study.json
.venv/bin/python -m pytest -q tests/test_trend_1h4h_research.py
```

Первая команда пишет новый файл. При наличии исходных 38 файлов ZIP и 38 соответствующих файлов .CHECKSUM в одной внешней папке можно запустить исследование офлайн.

```bash
.venv/bin/python scripts/run_trend_1h4h.py --archive-dir /path/to/archives --output trend-offline.json
```

Локальная контрольная сумма устанавливает целостность пары файлов. Происхождение локальных файлов остаётся UNVERIFIED, поэтому такой запуск сам по себе не проходит фильтр допуска к независимой проверке. Для публичной загрузки используются обычные HTTPS-запросы без ключей. Архивы, рыночные цены и пользовательские базы в репозиторий не включаются.

Тестовые архивы синтетические. Они проверяют полный путь из ZIP до 16 сравнений, детерминированность повторного запуска, причинность и сверку денежных потоков. Их экономические результаты не публикуются.
