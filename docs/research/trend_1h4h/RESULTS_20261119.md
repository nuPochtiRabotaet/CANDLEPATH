## Воспроизведение на Mac

Нужны Git и Python 3.12 (Python 3.14 не поддерживается этим pyproject.toml). Если Homebrew уже установлен: `brew install python@3.12`. Ниже создаётся новая папка, существующие установки не меняются. В случае отсутствия Git macOS предложит Command Line Tools.

```bash
(
set -eu
TREND_DIR="$(mktemp -d "$HOME/CandlePath-trend-XXXXXX")"
git clone --single-branch --branch research/v09-trend-1h4h-preregistered   https://github.com/nuPochtiRabotaet/CANDLEPATH.git "$TREND_DIR/repo"
cd "$TREND_DIR/repo"
git checkout --detach f7022087be76156bcec67688ebfc2a25d550c3f4
test "$(git rev-parse HEAD)" = f7022087be76156bcec67688ebfc2a25d550c3f4
python3.12 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
export MOEX_DATA_DIR="$TREND_DIR/isolated-data"
.venv/bin/python -m pytest -q tests/test_trend_1h4h_research.py
.venv/bin/python scripts/run_trend_1h4h.py --output "$TREND_DIR/trend-study.json"
printf 'Результат: %s\n' "$TREND_DIR/trend-study.json"
)
```

Это инструкция воспроизведения; выполнение на физическом Mac не проверено. Код 0 означает рассчитанный EXPLORATORY, а не разрешение торговать. Код 2 означает NOT EVALUABLE: см. error и archive_error в созданном JSON. Выходной файл должен быть новым. Не подменять закреплённые зависимости при ошибке установки: сохранить точную ошибку.

Штатный выход — один агрегированный JSON: provenance и хеши в data, base/double и решения в paths, интервалы и p в statistics. Архивы загрузчик обрабатывает в памяти и не сохраняет. Отдельный CSV сделок эта команда не выпускает.

Офлайн-путь поддерживается: 38 исходных ZIP и 38 файлов `.zip.CHECKSUM` в одной папке, BTCUSDT и ETHUSDT, месяцы 2024-01…2025-07. Примеры имён: `BTCUSDT-1h-2024-01.zip`, `BTCUSDT-1h-2024-01.zip.CHECKSUM`. Не добавлять август 2025 и более поздние месяцы. Из корня закреплённого репозитория:

```bash
.venv/bin/python scripts/run_trend_1h4h.py   --archive-dir "$HOME/CandlePathArchives"   --output "$HOME/trend-offline-new.json"
```

Даже при совпадении контрольных сумм локальный путь помечает provenance как UNVERIFIED и не даёт допуска. Не менять эту отметку вручную. Архивы и сырые рыночные цены в репозиторий не включены.
