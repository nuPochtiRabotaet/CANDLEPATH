# Risk Assessment Engine v0.4

Методика исследовательская и консервативная. Все пороги ниже — внутренние эвристики проекта, не норматив регулятора, не медицинская/психометрическая оценка склонности к риску и не валидированная вероятность убытка.

## Данные и модель

Advisor принимает полную структуру профиля: сумма 1–1e9 ₽, срок 1–60 месяцев, допустимое снижение 0.1–100%, low/medium/high, boolean потребности в деньгах раньше. Частичный профиль считается незаполненным, некорректные значения отклоняются. Общий анализ без профиля использует 20 торговых дней и условные 5000 ₽, это не персональный вывод.

Ряд должен иметь упорядоченный уникальный DatetimeIndex и конечные положительные CLOSE. Минимум для личной оценки: `max(126, 2 × horizon + 1)` закрытий. Условный месяц = 21 торговый день. Более 252 дней не моделируются, срок не обрезается. Реальная история старше 7 календарных дней или из будущего считается критическим пробелом. Это проверка возраста, не календарь торгов; официальные длительные остановки требуют ручного анализа. Демо исключено из проверки возраста и явно маркировано.

Рублёвые акции/фонды поддерживаются; отсутствие лота, иной класс или неподтверждённая валюта — критический пробел. Дневное изменение более 25%, предупреждения покрытия — неопределённость. Дивидендные/сплитовые корректировки не выполняются. Наличие похожей истории не доказывает стационарность.

Для Advisor запускаются block bootstrap и независимый historical bootstrap, одинаковые цены/срок/seed/издержки. Позиция удерживается до конца горизонта; стоп не ограничивает риск. Выводятся 5-й процентиль, медиана и 95-й процентиль block bootstrap, сравниваются оба метода. GBM доступен в отдельной Time Machine, не выбирается автоматически ради лучшего результата.

## Карта факторов

| Фактор | Правило и влияние |
|---|---|
| Просадка | Envelope = максимум исторической просадки, модулей 5-го процентиля просадки траекторий и положительной ES двух моделей. Выше пользовательского лимита → обязательный конфликт |
| Рыночная тяжесть | Максимум трёх tier: историческая просадка (10/20/35%), годовая волатильность (15/30/50%), ES (5/15/30%). 0/1/2/3 превышения = низкий/умеренный/высокий/очень высокий |
| Срок | Не более 3 месяцев либо деньги нужны раньше → конфликт |
| Предпочтение | low при высоком/очень высоком рынке; medium при очень высоком → конфликт |
| Концентрация | После покупки тикер >35% NAV для акции или >50% для фонда → конфликт. Границы строго `>` |
| Ликвидность | Медиана последних 20 VALUE, минимум 10 конечных неотрицательных наблюдений; при отсутствии VALUE допустима подписанная оценка CLOSE×VOLUME. Нулевой оборот, позиция >1% дневного оборота или bid/ask спред >2% → конфликт при наличии профиля. Нет оборота/спреда → неопределённость |
| Несогласие моделей | Разница 5-х процентилей конечной доходности >5 процентных пунктов → неопределённость |
| Издержки | Условный полный оборот >3% → конфликт, >1% и ≤3% → неопределённость |
| Лоты | Суммы не хватает на один лот с издержками → конфликт |
| Портфель не указан | Неопределённость; отсутствие данных не означает диверсификацию |
| Фундаментальные данные | Пока всегда неопределённость: бизнес, состав фонда, расходы и текущая оценка не проверены |
| Прочее | Инфляция, регуляторные/корпоративные события неизвестны, не объявляются низким риском |

Известный совокупный уровень — **максимум**, не среднее. Покрытие всегда частичное. При отсутствующих ценовых оценках текущая реализация всё равно выводит агрегат доступных факторов; рядом нужно читать критические пробелы. Это не полный количественный риск портфеля.

## Деньги, комиссии, концентрация

`c = (commission_pct + slippage_pct) / 100` на сторону. `qty = floor(amount / (last_close × (1+c) × lot)) × lot`. Entry cost = qty×close×c. Остаток бюджета лежит без процентов. Итог бюджета = amount + allocated_cash×net_return; net_return уже содержит покупку и продажу, поэтому комиссия не вычитается второй раз. Условная цена — последнее историческое CLOSE, не обещание исполнения по ней. Roundtrip cost при плоской цене = `1 − (1−c)/(1+c)`.

Контекст портфеля задаётся явно: NAV, стоимость тикера, cash, источник покупки. При новых деньгах NAV после = NAV + amount − entry cost; при existing_cash = NAV − entry cost. Числитель доли = прежняя стоимость тикера + invested. Проверяются доступные деньги и held+cash≤NAV. Другие акции того же эмитента, отрасли, корреляции и состав фондов не объединяются.

## VaR, ES и границы

VaR95 loss = отрицательный 5-й процентиль net return. ES95 loss = отрицательное среднее худших `ceil(N×.05)` исходов. Отрицательные VaR/ES возможны при прибыли во всех хвостовых сценариях; это не нулевой риск. Для тяжести риска используется неотрицательная часть ES. Просадки траекторий включают условную ликвидационную стоимость с издержками.

Ни исторический максимум, ни envelope, ни 5-й процентиль не являются пределом будущих потерь. Возможна потеря всей позиции. Bootstrap повторяет прошлые движения и не создаёт все мыслимые новые шоки. Дневные барьеры Time Machine исполняются по CLOSE с перескоком, не по гарантированной цене стопа. Модель GBM калибрует среднее и std дневных логарифмических доходностей, не вычитает sigma²/2 повторно.
