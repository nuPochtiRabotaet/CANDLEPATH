Исходные данные тестовых котировок и CSV/XLSX — fixtures, а не реальные рыночные цены. Они не выдаются пользователю как live. В этой итерации не выполнялись новая чистая установка зависимостей (locks не менялись), полноценный Chromium/Safari и физический Mac. UI проверен Streamlit AppTest, а не заявлен как проверенный в настоящем браузере. Optional скрипт scripts/verify_browser.py адаптирован, но в текущей среде не запускался.

Реальный отчёт Альфы не предоставлен. Тестовые таблицы доказывают работу описанного нормализованного формата, а не любого многостраничного отчёта брокера. Автосинхронизации с Альфой нет.

## Воспроизведение

```bash
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m scripts.verify_http
```

Живые проверки: scripts.verify_live / scripts.verify_advisor_live, требуется доступный MOEX ISS. Отдельный optional Chromium smoke требует Playwright и установленный браузер; результаты в artifacts/browser, снимки только при явном --screenshots. Скрипт браузера не входит в подтверждённый результат текущей итерации.

Сборка исходного архива: `python -m scripts.package_release`. Архив содержит MANIFEST.sha256, не включает пользовательские базы, резервные SQLite-копии, секреты, кеши или runtime.
