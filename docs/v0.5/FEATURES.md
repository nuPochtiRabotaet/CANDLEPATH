# Статус функций v0.5

| Возможность | Статус |
|---|---|
| Старые Reader/MCP, Time Machine, стратегии, Advisor, отчёты и история | Сохранены; регрессионные тесты проходят |
| Один счёт Альфа-Инвестиций | Реализован локально, без подключения к брокеру |
| Начальные остатки: бумаги, средняя цена, деньги, дата | Реализованы без создания фиктивных покупок |
| Добавление, исправление, удаление ошибочных записей | Реализованы, с проверкой журнала и аудитом |
| Автооценка через MOEX, структура, P&L и стресс | Реализованы; новый онлайн-путь не подтверждён живым API в текущей среде |
| CSV/XLSX, предпросмотр и проверка дублей | Реализованы на нормализованных таблицах, проверены тестовыми файлами |
| Произвольный полный нативный отчёт Альфы | Не подтверждён: нет образца |
| Собственный JSON-журнал | Экспорт и восстановление в пустой журнал |
| TWR/просадка с учётом денежных потоков | По загруженной полной истории оценок, без выдуманных цен |
| Полная доходность до быстрого переноса | Неизвестна, не вычисляется |
| Котировки при закрытом рынке | Датированное закрытие, если LAST отсутствует и есть достаточные данные |
| Несколько счетов/брокеров | Предусмотрен account_id; UI пока один счёт |
| Автоматическая синхронизация Альфы | Не реализована |
| Налоги, FX, корпоративные действия, облигационный total return | Не реализованы |
| Полный визуальный редизайн и макеты | Отложены по указанию пользователя |
| Mac Apple Silicon / Safari / Python 3.13 | Нужна отдельная проверка |
