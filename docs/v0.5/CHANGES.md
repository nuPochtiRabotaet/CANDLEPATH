# Изменения v0.5.0

Продолжена существующая v0.4; математические симуляции, стратегии, Reader, MCP, Advisor и история исследований сохранены. CSS и тема не перерабатывались. Главная дополнена функциональными показателями сохранённого портфеля; макеты и визуальный редизайн не создавались.

- PortfolioStore: миграция старого SQLite с резервной копией, постоянными ID и account_id. Версия журнала, атомарное исправление/удаление с полным воспроизведением, журнал изменений и защита от устаревших действий из другого окна.
- Начальные остатки как отдельный вид события; отсутствие полной истории явно отражено в P&L и расчёте доходности.
- Отдельный portfolio_service без Streamlit: оценки MOEX, преобразование облигационных процентов в рубли только с подтверждёнными номиналом/НКД, идентификация инструментов, контекст Advisor.
- portfolio_import: ограниченный CSV/XLSX/JSON, сопоставление, точные тикеры/ISIN/названия, ошибки строк, проверка повторов, атомарная запись после предпросмотра.
- portfolio_ui: функциональные вкладки «Позиции», «Операции», «Выплаты», «Анализ», «Импорт», компактная форма по типу события, карточка выбранной бумаги в правой колонке Streamlit, быстрый перенос и исправление ошибочных записей.
- После записи все показатели используют новый журнал. Advisor берёт контекст сохранённого портфеля; старый результат в активной сессии сбрасывается после правки. Архив исследований не переписывается.
- Единый интерфейс с раскрываемыми деталями; Beginner/Advanced больше не переключаются.
- Кнопка обновления инвалидирует кеш котировок в UI и DataEngine, история цен в кеше сохраняется.
- Закрытая сессия без LAST: только явно датированное реальное дневное закрытие. Цена покупки, PREVPRICE без даты и синтетика не подставляются.

Исторические отчёты v0.4: docs/v0.4. Полная нативная выгрузка Альфы, автосинхронизация и физический Mac/Safari пока не проверены.
