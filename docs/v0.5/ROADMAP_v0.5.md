# Состояние v0.5

Функциональная итерация завершена в пределах описанного MVP: журнал с исправлением/удалением, начальные остатки, независимые сервисы портфеля, автооценка, нормализованный импорт с предпросмотром, связь с существующим Advisor. Визуальные макеты и редизайн остановлены по указанию пользователя.

Следующие проверки требуют внешних материалов/среды:

1. Обезличенный настоящий брокерский отчёт Альфы: адаптер его конкретных секций, сверка цен/НКД/комиссий и денежных остатков.
2. Проверка текущей автооценки при доступном MOEX и на пользовательском Mac; сейчас сеть среды возвращает тайм-аут.
3. При необходимости — надёжная автоматическая история портфельных оценок и следующий этап многосчётности. Пока исторические показатели требуют реальной истории оценок CSV.
4. Официальная брокерская синхронизация — отдельная задача после проверки доступных интерфейсов.
5. Визуальный редизайн — позднее, после проверки основных сценариев. CSS/тема сейчас не менялись.
