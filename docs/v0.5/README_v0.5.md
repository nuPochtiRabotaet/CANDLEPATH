# MOEX Intelligence 0.5.0

Функциональное обновление существующей v0.4. Оформление сохранено. Локальная платформа исследования российского рынка: MOEX Reader, симуляции, бэктесты, виртуальный портфель и **Investment Advisor** с объяснимыми правилами. Python, Streamlit, официальный MCP SDK. Предыдущая версия сохранена в `legacy/MOEX_Intelligence_v0.3.0.zip`; исходные архивы Reader/Time Machine/bridge также сохранены.

## Запуск на Mac

Нужен Python **3.12** (рекомендуется; 3.13 допускается скриптом, отдельно не проверялся). Установщик: [python.org](https://www.python.org/downloads/macos/).

1. Распакуйте архив целиком в обычную папку, например `~/Downloads/moex-intelligence-v0.5`.
2. Откройте `setup.command`. Он создаст `.venv` и установит зависимости с проверкой SHA-256. Дождитесь «Настройка завершена».
3. Откройте `start.command`. Приложение откроется в браузере на `http://127.0.0.1:8501` либо свободном порту до 8510.
4. Для завершения откройте `stop.command`. Закрытие вкладки само по себе сервер не останавливает.

Если macOS запрещает открыть `.command`, используйте Terminal по [инструкции macOS](docs/MACOS.md). Не отключайте системную защиту целиком. Скрипты не требуют `sudo` и не изменяют системный Python.

Ручная установка и запуск из корня проекта:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python -m moex_intelligence.launcher start
```

## Первое исследование

На странице «Оценить вложение» оставьте SBER, источник MOEX ISS. Укажите сумму, срок, допустимое снижение и предпочтительный риск. Подтвердите, что это ваши условия, затем нажмите «Проанализировать инвестицию». Если данные ещё не загружены, Advisor загрузит историю и котировку сам. Необязательный профиль можно сохранить в настройках, знакомство можно пропустить.

Для теста без интернета **явно** выберите слева «Демо · искусственные данные». Синтетическая история и учебный вывод подписаны. При сетевой ошибке демо автоматически не включается. Если ISS недоступен с VPN, проверьте доступ к `iss.moex.com` в своём соединении; приложение не управляет VPN.

Условия, данные и результаты сохраняются как снимок в истории исследований. Открытие старого исследования не пересчитывает его. Отдельная кнопка повторного исследования создаёт новую запись. Доступны Markdown-отчёт и CSV исходных цен.

**Что означает вывод:** превышение допустимых потерь, короткий срок, потребность в деньгах или чрезмерная концентрация блокируют благоприятный вывод. Недостаток данных явно указан. Фундаментальных данных пока нет: текущая версия не объявляет бумагу привлекательной только потому, что она росла. Внутренний балл — соответствие правилам, не вероятность заработать и не рейтинг справедливой стоимости.

## Что есть в интерфейсе

| Раздел | Возможности |
|---|---|
| Обзор | Задачи для новичка, история актива, срез IMOEX/SBER/SBMX по запросу, последние исследования |
| Исследовать актив | Поиск, класс инструмента, свечи/CSV, сравнение с SBMX или IMOEX на общих датах |
| Оценить вложение | Лоты, две bootstrap-модели, сценарии в рублях, карта рисков, правила вердикта, влияние на долю тикера |
| Сценарии | Block bootstrap, независимый bootstrap, GBM; цель/стоп либо удержание; комиссии, VaR/ES, траектории |
| Стратегии | Buy & Hold, SMA/EMA crossover, RSI; отложенный период, бенчмарк, журнал |
| Мой портфель | Начальные остатки, операции с исправлением/удалением, котировки MOEX, CSV/XLSX/JSON с предпросмотром, выплаты, TWR по оценкам и стресс |
| ИИ и отчёты | Детерминированный отчёт и подключение внешнего ИИ через MCP |
| История / Настройки | Снимки с проверкой целостности, профиль; единый интерфейс с раскрываемыми подробностями |

Тёплая графитовая тема, терракотовый акцент, контекстный словарь. Режимы Beginner/Advanced убраны; дополнительные расчёты раскрываются по необходимости. Встроенного LLM-чата нет; ключи OpenAI/Anthropic не требуются.

## Портфель в v0.5

- **Начальные остатки:** «Мой портфель → Позиции → Быстрый перенос без истории сделок». Найдите бумагу по названию/ISIN либо введите тикер, количество в бумагах и среднюю цену покупки. Добавьте свободные деньги и дату переноса. Это запись начального остатка, а не набор выдуманных покупок; доходность до переноса неизвестна.
- **Операции:** форма показывает поля выбранного типа. Сохранение пересчитывает деньги, позиции, стоимость, структуру, выплаты и стресс. Покупка требует денег в журнале; короткие позиции и заём не поддерживаются.
- **Исправление:** выберите запись во вкладке «Операции», измените значения и сохраните. Удаление ошибочной записи требует отметки в той же форме. В обоих случаях весь журнал проверяется в одной SQLite-транзакции; если нарушается остаток денег/бумаг, ничего не сохраняется. Реальная продажа вводится отдельной операцией.
- **Котировки:** автоматически из MOEX. Если LAST отсутствует, возможно явно датированное дневное закрытие; для облигации нужны подтверждённые номинал и НКД на дату цены. Цена покупки не подставляется. Без оценки хотя бы одной позиции полная стоимость и контекст Advisor недоступны. Кнопка обновления сбрасывает оба кеша цен.
- **Импорт:** CSV UTF-8/Windows-1251, таблицы XLSX, восстановление собственного JSON. Предпросмотр, сопоставление колонок, распознавание тикеров/ISIN/точных названий, проверка повторов, исключение строк и итоговые остатки до записи. [Форматы и ограничения](docs/IMPORT.md).
- **Связь с аналитикой:** выбранная позиция открывает исследование, Advisor или сценарии с тем же тикером. Advisor может использовать актуальный снимок своего портфеля без ручного ввода его стоимости. Сохранённые исследования остаются снимками, а не обновляются незаметно.

**Импорт всех произвольных разделов настоящего отчёта Альфы ещё не подтверждён:** образец отчёта не предоставлен. Выбирайте одну таблицу операций либо таблицу текущих позиций и проверяйте соответствие колонок. Итоговый денежный остаток сложного отчёта не угадывается: он считается из введённых операций, а в режиме начальных позиций задаётся явно. PDF, старый XLS, налоги, валютные сделки и корпоративные действия не поддерживаются; неизвестные строки блокируют импорт.

Один счёт Альфа-Инвестиций в интерфейсе; хранилище и блокировки учитывают `account_id` для будущих счетов/брокеров. Подключения к брокеру, ключей и синхронизации нет.

### Обновление с v0.4

Остановите v0.4 через её `stop.command`, сохраните копию `~/.moex-intelligence/`, затем распакуйте v0.5 в **отдельную** папку и выполните `setup.command → start.command`. Обе версии по умолчанию используют прежний каталог данных. Первый доступ v0.5 к старому журналу делает SQLite-резервную копию `portfolio.sqlite3.v04-backup`, сохраняет ID и порядок записей, добавляет служебные таблицы. Исследования и настройки не переносятся вручную и не стираются. Не запускайте одновременно старую v0.4: она не поддерживает начальные остатки v0.5. Возврат на v0.4 возможен после остановки v0.5 и восстановления резервной копии; записи, добавленные после копии, в ней отсутствуют.

## MCP и совместимость

Из корня проекта:

```bash
.venv/bin/python -m moex_intelligence.mcp_server
```

В клиенте с поддержкой локального stdio используйте абсолютные пути:

```json
{"mcpServers":{"moex-intelligence":{
  "command":"/ABSOLUTE/PATH/moex-intelligence-v0.5/.venv/bin/python",
  "args":["-m","moex_intelligence.mcp_server"],
  "env":{"PYTHONPATH":"/ABSOLUTE/PATH/moex-intelligence-v0.5"}
}}}
```

Объединённый сервер содержит **15** инструментов. Сохранены прежние 13: `search_security`, `get_quote`, `get_daily_history`, `analyze_history`, `get_market_snapshot`, `time_machine_simulate`, `time_machine_demo`, `get_instrument`, `strategy_backtest`, `portfolio_analyze`, `portfolio_stress`, `compare_market_scenarios`, `research_report`. Добавлены `evaluate_investment` и `compare_investments`.

Пример аргументов `evaluate_investment`:

```json
{"symbol":"SBER","profile":{"amount":5000,"horizon_months":12,"max_drawdown_pct":5,"risk_preference":"low","needs_money_early":false},"scenarios":2000,"seed":42,"demo":false}
```

MCP не читает личный портфель автоматически: контекст передаётся явно. Числа рассчитывает Python, ИИ интерпретирует результат. Торговых API нет. `python server.py` сохраняет отдельный Reader с ровно пятью прежними инструментами (его проверяет `python smoke_test.py`). Старые импорты `moex_data`, `simulator`, `time_machine_core` и `time_machine_dashboard/app.py` сохранены.

HTTP доступен только локально:

```bash
.venv/bin/python -m moex_intelligence.mcp_server --transport streamable-http
```

Адрес: `http://127.0.0.1:8000/mcp`, health: `/health`. Защита Host/Origin включена, публичный HOST запрещён. Облачный MCP-клиент не видит localhost Mac. Публикация с TLS/авторизацией — отдельная задача; инструкции о туннелях из старых архивов не применяются.

## Данные и сохранение

Дневная история заканчивается вчерашней московской датой. Наблюдения не заполняются синтетическими значениями. Сохраняются диапазон, источник, время загрузки и SHA-256 цен. Кеш в памяти до 64 ответов, TTL 300 секунд; UI и MCP имеют отдельные кеши общего слоя. При ошибке API просроченный кеш не выдаётся.

Личные данные находятся в `~/.moex-intelligence/`: `portfolio.sqlite3` и `research.sqlite3`. Для резервной копии остановите приложение и скопируйте оба файла. Переносить `.venv` между компьютерами не нужно. Состояние launcher и лог находятся в `.runtime/` рядом с кодом, исключены из ZIP/git.

Конфигурация через окружение (`.env` автоматически не читается): `MOEX_DATA_DIR`, `MOEX_CACHE_TTL`, `HOST`, `PORT`. Основные сообщения приложения — JSON в stderr; stdout зарезервирован для MCP.

Портфель: сначала `deposit`, затем `buy`/`sell`. Количество задаётся в бумагах; комиссия в рублях. Плечо/шорт запрещены. Оценки ручные, начальные значения — учётные, не текущие биржевые цены. Для TWR нужны оценки на все даты событий; пример формата в `examples/portfolio_valuations.csv`. Выплаты вводятся с источником, автоматической проверки документа нет. Для облигации нужна полная цена в рублях с действующим номиналом и НКД. Подробности сохранённого журнала и API — в [руководстве v0.3](docs/v0.3/ARCHITECTURE.md).

## Проверки и ограничения

```bash
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m scripts.verify_http
.venv/bin/python -m scripts.verify_advisor_live
```

См. актуальный [отчёт проверки v0.5](docs/TESTING.md). Автоматические тесты и HTTP MCP проверяются на Linux. В этой итерации живые запросы MOEX завершились тайм-аутом: текущая онлайн-оценка не подтверждена. Результаты живых проверок v0.4 относятся только к той итерации. Физический Mac и Safari отдельно не проверены.

Модельные частоты — не реальные вероятности. Потери могут быть хуже 5-го процентиля, вплоть до всей позиции. Цены не скорректированы на дивиденды/сплиты, налоги не включены. Облигации доступны для исследования, но Advisor не подменяет их купонную модель моделью акции. Индекс IMOEX — ориентир в пунктах, не покупаемый инструмент. Фундаментальный анализ, новости, полноценный LLM-чат и автоматический выбор альтернатив отложены.
