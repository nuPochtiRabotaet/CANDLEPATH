## Журнал архитектурных решений

| Решение от 2026-11-23 | Основание | Когда пересматривать |
|---|---|---|
| AD-01. Долгосрочная цель — один агент с исследовательскими инструментами и явным NO TRADE. | Один журнал намерений позволяет воспроизвести основание каждого решения. | Только если измерена задача, которую один агент с ограниченными инструментами не решает. |
| AD-02. Решение о риске, учёт и исполнение детерминированы и изолированы от модели. | Текст источника или изменение модели не должно расширять права на капитал. | Изменение границы полномочий требует отдельного security review. |
| AD-03. На старте один исполнитель на счёт, локальная транзакционная БД и отдельный headless-процесс. | Существующий Paper умеет транзакции и блокировку владельца. У двух разработчиков есть воспроизводимый путь отказа и восстановления. | Измеренная нагрузка, несколько хостов или требования HA потребуют нового решения о хранении и fencing. |
| AD-04. Допуск раздельный для Paper, Official Demo и Restricted Live Spot. | Виртуальный fill, принятая демо-заявка и реальная защищённая позиция требуют разных свидетельств. | При изменении площадки, версии стратегии или условий мандата. |

За продуктовые ограничения отвечает владелец. Автор задачи отвечает за реализацию, второй разработчик — за независимое ревью. Этап переводится в следующий статус по приложенным свидетельствам и решению людей. [История прежних решений](../../CANDLE_VISION.md)
