# UX review — rc2

Сохранены графитовый terminal, chart instance, zoom, overlays и четыре пресета. В modal наверх вынесены gross quantity, net received, ориентировочный debit/credit, риск; остальные параметры раскрываются в «Подробнее». Consent/кнопки закреплены внизу. Escape сначала ждёт серверную отмену — исправлена гонка быстрого Cancel → новый Prepare.

Amount содержит явный выбор Notional / Total. Quantity — вычисляемое read-only поле в amount-режиме; поле суммы реально скрывается в quantity-режиме (добавлено приоритетное правило [hidden]). Новая комиссия/издержки не вычисляются второй формулой в JS. Во время неподтверждённого ввода карточки показывают ожидание серверного расчёта.

QA screenshots сняты реальным Chromium с работающего Streamlit: docs/rc2/browser. Там синтетические данные, включая base-fee-preview и настройки. Modal маркируется QA SYNTHETIC. Production screenshot отдельно показывает реальную ошибку сети. Проверены ширины 1024/1280/1440/1920; chart >50% viewport, без горизонтального overflow. Safari/macOS требуют проверки.

Остаётся до FINAL: убрать внутреннюю прокрутку Assistant, UI выбора конкретного сигнала, новый trade journal/statistics и подтверждение действующих TP/SL. Drag пока меняет только черновик. Base fee может дать неторгуемый остаток; это явно предупреждается, ручной LOCAL PAPER вход пока не блокируется только advisory-политикой.

В форме комиссии два явных radio-варианта USDT/Актив заменяют нестабильно открывавшийся dropdown Streamlit; сумма и стоимость проверены после сохранения выбранного варианта.
