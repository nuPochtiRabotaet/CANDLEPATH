## Известные ограничения и отложенные функции

- Встроенного диалогового LLM нет. Правая панель — справка, не чат. Для ИИ используется внешний MCP-клиент. Нет интеграции с OpenAI/Anthropic, ключи не сохраняются.
- Фундаментальная стоимость, отчётность, новости и состав фондов не проверены. Поэтому текущий сквозной Advisor выдаёт study/unsuitable/insufficient, а категория consider зарезервирована для развития.
- Альтернативы Advisor — подписанные направления исследования, не автоматически ранжированные/проверенные варианты покупки. Количественное сравнение цен доступно отдельно в Explorer; купонная доходность облигации с акцией не сравнивается.
- Ликвидность оценивается грубо по дневному обороту и доступному bid/ask. Нет стакана, очереди исполнения и реального impact.
- Концентрация объединяет только один тикер; нет look-through фондов, отраслей и корреляций. Portfolio Health не является полноценной оптимизацией.
- Нет автоматической синхронизации портфеля, котировок/выплат, редактирования старых событий в UI, сценарной корреляционной модели или многовалютного учёта. Оценки портфеля ручные.
- Для облигаций доступны метаданные, история и ручной полный учёт цены. Advisor/симуляции/бэктест цен акций не подменяют купонную модель.
- История primary board может быть короче запрошенной; прежние режимы не склеиваются. Цены без корректировки выплат и сплитов; отсутствующие торговые дни не заполняются.
- Численная модель Advisor до 12 месяцев; ввод более длинного срока сохраняется, но получает ограничение. Нет автоматического изменения условий пользователя ради хорошего вердикта.
- UI использует боковой выбор тикера, встроенное сворачивание панели; отдельный верхний глобальный поиск, Command-K/Command-B и нативные окна macOS не реализованы.
- Новый интерфейс использует сохранённые компоненты Strategy/Portfolio/AI; это функциональный MVP, не полная самостоятельная реализация каждой страницы из расширенного задания.
- Отчёт выгружается в Markdown, PDF/DOCX нет. Локальная история без шифрования, подписи и облачной синхронизации.
- Mac Finder/Gatekeeper/Safari не тестировались физически. Python 3.13 не проверялся. Тесты сети выполнены в текущей среде, реальный VPN пользователя недоступен.
- Нет публичного сервера, брокерских приказов, обещаний прибыли. Проект не опубликован на GitHub.
