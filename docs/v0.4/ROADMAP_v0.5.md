# Roadmap v0.5

Порядок основан на надёжности выводов. Положительный сигнал не должен появиться раньше проверенных входных данных.

1. **Приёмка на реальном MacBook Air.** Python 3.12 ARM64, установка с нуля, Finder/Gatekeeper, Safari, restart/stop, занятый порт, ISS с разными соединениями. Исправить платформенные проблемы до расширения функций.
2. **Качество данных.** Торговый календарь, явная история смены board/лота, корпоративные события, контроль total-return рядов и источников. Тестировать ошибочные и частично доступные ответы.
3. **Валидация риск-правил.** Исследовать чувствительность порогов, частоту конфликтов, зависимость от окна/режима. Раздельно оценивать model uncertainty и переносимость потерь. До этого не называть балл вероятностью.
4. **Проверяемое сравнение альтернатив.** Один срок/валюта/денежные потоки, расходы фонда и его состав. Для облигаций сначала НКД/амортизация/купоны/погашение и дюрация; затем сравнение с акциями.
5. **Портфель.** Безопасный UI исправления событий, импорт с предварительным просмотром, проверка источников оценок, полный состав эмитентов/фондов, корреляционный стресс с достаточной историей.
6. **Фундаментальные данные.** Только с датой публикации и источником, без использования будущей отчётности в истории. Рассмотреть текущую оценку и долговую нагрузку. После независимых тестов пересмотреть условия consider, не просто убрать флаг uncertainty.
7. **LLM в интерфейсе.** Выбираемый провайдер и явная передача данных, ключи вне БД исследований, инструментальные вызовы через существующие функции, ссылки и запрет менять численный вердикт в тексте. Без рабочего провайдера не показывать фиктивный чат.
8. **UX.** Верхний поиск, доступность/клавиатура, управление правой панелью, маленькие экраны, экспорт PDF. Горячие клавиши с учётом конфликтов браузера.

Критерий каждой итерации: самостоятельный работающий сценарий, тесты на отрицательные входы, источник данных и документированные границы. Публичное размещение и брокерский доступ не входят автоматически в эту дорожную карту.
