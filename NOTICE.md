# Происхождение и границы использования

Исходные проекты предоставлены пользователем; их неизменённые архивы и хеши включены в поставку. Новая версия сохраняет работоспособные компоненты и расширяет их. Права на внешние данные и сторонние библиотеки принадлежат их правообладателям. Этот файл не назначает новую лицензию предоставленному ранее коду. Перед публичной публикацией владелец проекта выбирает лицензию и проверяет условия MOEX на использование/распространение данных.

Примеры портфеля и browser screenshots используют явно синтетические данные. JSON с `live-verification` фиксирует реальные публичные ответы MOEX для проверки интеграции; это не рекомендация совершать сделки.
