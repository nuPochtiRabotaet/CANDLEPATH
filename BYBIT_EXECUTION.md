# Граница Bybit Demo и будущего Live Manual

В v0.8.1 сохранены Public Market Data, Local Paper и server-side Read Only. DemoAdapter и Live submit не реализованы. Кнопки/настройки для включения реальных заявок отсутствуют. Ни стратегия, ни сигнал не вызывают биржевое submit.

Инструкции подключения действующего Demo в этой сборке нет: выдавать фиктивную инструкцию активации было бы неверно. Следующий этап требует проверки официальной платформы аккаунта, отдельного demo endpoint/ключа, независимого баланса/журнала, orderLinkId, baseCoin units, price/quantity/notional validation, fee API, asynchronous ACK и private WS/REST reconciliation. ACK не равен Fill; чистая FSM-сверка v0.8 сохранена, но не подключена к биржевому исполнению.

Будущий Live потребует отдельного review и явного разрешения владельца, Spot без плеча/вывода, server-side секретов, IP allowlist где возможно, независимого Risk Manager, preview/подтверждения, kill switch, лимитов, восстановления и проверки биржевых Spot TP/SL. Локальный Python-stop не должен выдаваться за серверную защиту Bybit.

Региональные домены не перебираются и ограничения доступа не обходятся. Проверка текущей среды: network.json. Успех на Mac, сообщённый пользователем, не заменяется отрицательным заключением по облачной сети.
